◆ SMOLRTSP_MAX_HEADER_VALUE

#define SMOLRTSP_MAX_HEADER_VALUE   1024

The maximum length, in bytes, of a single RTSP header value accepted by SmolRTSP_Header_parse.

Values longer than this are rejected with #SmolRTSP_ParseError_HeaderValueTooLong. This bounds the memory that header parsing may touch and guards against denial-of-service from unbounded header values sent by an untrusted peer. The parsers are compiled with this value, so an override has to be in the library's own build: configure with -DSMOLRTSP_MAX_HEADER_VALUE=<n>, which also defines it for consumers of the target.
